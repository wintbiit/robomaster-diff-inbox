Notice on RMUC 2025 Final Robot Assessment (for international teams)

2025-05-19

<header> Participants: All participating teams from Hong Kong, Macao, Taiwan, and overseas that have passed the Mid-term Progress Assessment. Participation: Team leaders fill out and submit the questionnaire: https://djistore.wjx.cn/vm/rQwgBUP.aspx. </header>

Submission Time: From 18:00 on May 31, 2025, to 18:00 on June 2, 2025 (Beijing Time).

Submission Opportunities: 1 attempt.

Passing Criteria: Teams will be ranked based on their scores in the Final Robot Display Assessment. The top 96 teams from mainland China can pass this section; under the same assessment criteria, a certain portion of teams from Hong Kong, Macao, Taiwan, and overseas can pass.

Assessment Content:

1.Final Robot Display

2.Technical Proposal

3.Project documentation (including Project Analysis, Cost Report, Expenditure Record, and Robot BOM Record)

Note: The final robot assessment criteria differ from those in the participant manual, please adhere to this notice.

*Final Robot Display:* Record videos following the sequence in the " RoboMaster 2025 University Series Technical Assessment Criteria ( https://www.robomaster.com/en-US/resource/pages/announcement/1778 )." to display the current completion status of each robot. You should demonstrate as much progress as possible. To prevent issues with reused video materials leading to discrepancies between displayed and actual progress, choose one of the following methods for shooting/submitting proof based on your actual situation. Footage/proof materials that do not meet these requirements will only score up to 50% of the full score for the corresponding content.

a. ( Click here ( https://terra-1-g.djicdn.com/b2a076471c6c4b72b574a977334d3e05/%E8%A3%85%E7%94%B2%E5%9B%BE.pdf ) ) Download the technical assessment armor diagram, print it, and affix it to the robot armor or the reserved installation position of the armor. For robots that do not need armors, like aerial robots, refer to method b.

b. ( Click here ( https://terra-1-g.djicdn.com/b2a076471c6c4b72b574a977334d3e05/%E8%83%8C%E6%99%AF%E6%9D%BF.pdf ) ) Download the technical assessment background board, print it on A3 paper, display it clearly throughout the video using a laptop fullscreen or other physical methods. Post-production synthesis is prohibited.

Shoot videos sequentially according to the "RoboMaster 2025 University Series Technical Assessment Criteria." [ Click to view ( https://www.robomaster.com/en-US/resource/pages/announcement/1778 ) ], edit the recorded materials into a complete video according to the template sequence, and submit the video link.

*Data Reprot:* Refer to the "RoboMaster 2025 Technical Assessment Data Report Template" (Download Template: Click here ( https://terra-1-g.djicdn.com/b2a076471c6c4b72b574a977334d3e05/Template%20RMU%202025%20Final%20Robot%20Assessment%20Data%20Report.xlsx ) ), submit the Excel document.

*Technical Proposal:* Refer to the "RMUC 2025 Technical Proposal Template" (Download Template: Click here ( https://terra-1-g.djicdn.com/b2a076471c6c4b72b574a977334d3e05/Template%20%20RoboMaster%20Technical%20Proposal.docx ) ), submit a PDF document. Choose the most representative robot equipped with the most advanced technologies this season as an example for the report.

*Project Documentation:*

a. Project Analysis: Refer to the "RMUC 2025 Project Analysis Template" (Download Template: Click here ( https://terra-1-g.djicdn.com/b2a076471c6c4b72b574a977334d3e05/Template%20RoboMaster%20Final%20Robot%20Assessment%20Project%20Document.docx ) ), submit a PDF document.

b. Cost Report: Refer to the "RMUC 2025 Cost Report Template" (Download Template: Click here ( https://terra-1-g.djicdn.com/b2a076471c6c4b72b574a977334d3e05/Template%20%20RoboMaster%20Cost%20Report.docx ) ), submit a PDF document.

c. Expenditure Record: Refer to the "RMUC 2025 Expenditure Record Template" (Download Template: Click here ( https://terra-1-g.djicdn.com/b2a076471c6c4b72b574a977334d3e05/Template%20%20RoboMaster%20Expenditure%20Record.xlsx ) ), submit an Excel document.

d. Robot BOM Record: Refer to the "RMUC 2025 Robot BOM Record Template" (Download Template: Click here ( https://terra-1-g.djicdn.com/b2a076471c6c4b72b574a977334d3e05/Template%20%20RoboMaster%20Robot%20BOM%20Record.xlsx ) ), submit an Excel document.

*Document Requirements:*

1.PDF Format Documents: Main text should be Source Han Serif font size 10.5pt for Chinese or Times New Roman font size 10.5pt for English; fixed 1.5 line spacing; document naming: School + Team Name + Section Name.

2.Excel Format Documents: Main text should be Source Han Serif font size 11pt for Chinese or Times New Roman font size 11pt for English; set to auto-wrap, auto-adjust row height, and column width; maintain vertical center alignment for all text unless otherwise necessary, and align text uniformly either to the left or center horizontally; document naming: RMUC2025 + School Name + Team Name + FInal Robot Assessment.

3.Video: Resolution higher than 720P; add subtitles or cue cards explaining each process in the video; the video should have a tight pace, with each robot's function display time not exceeding 10 minutes; upload the video to YouTube and optionally set a viewing password.

*Permissions Granted:*

1.Full access to the referee system and permission to submit competition feedback.

2.Scores in Project Documentation and Technical Proposal from this section will affect the initial coin amount in each match during the regional competitions for the team.
