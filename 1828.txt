Notice on RoboMaster 2025 University Championship & University League Referee System Exam (Basics)

2025-03-28

*Participants:*

1、RMUC: All teams that have passed the Season Planning. Mandatory for both Tier-1 and non-Tier-1 teams in Mainland China.

2、RMUL: All teams that have passed the Season Planning.

*Recommendations:*

1、All team members should familiarise themselves with the referee system basics for future borrowing and operation.

2、Only submissions from Team Captains, Vice Captains, or Project Managers will be considered valid.

*Passing Requirements:*

1、A perfect score (100/100) in one submission. Responses must include the participant’s name, and only those submitted by Captains/Vice Captains/Project Managers will count.

2、RMUL: Each team must have at least one valid passing submission, regardless of the number of projects entered.

3、RMUC: Each team must have at least one valid passing submission. Teams that pass the RMUL Referee System Exam (Basics) automatically qualify for this stage in RMUC.

*Participation Method:*

1、Team-based registration.

2、Due to varying schedules across regions and event categories, assessments will be conducted via Wenjuanxing links at the following times:

*Assessment Content:*

1、 RoboMaster Referee System User Manual ( https://www.robomaster.com/en-US/products/components/referee )

2、 Referee System Module Specifications (same as 2020 season) ( https://www.robomaster.com/en-US/products/components/referee )

3、 FAQ ( https://www.robomaster.com/en-US/products/components/referee ) and Referee System acceptance guidelines ( https://terra-1-g.djicdn.com/b2a076471c6c4b72b574a977334d3e05/Referee%20System%20acceptance%20guidelines.pdf )

*Format:*

1、25 randomly generated questions (4 points each, 100 total).

2、Time limit: 60 minutes (max 3 minutes per question).

*Attempts:*

Unlimited retries within the assessment window. Passing on any attempt qualifies the team.

*Privileges Upon Passing:*

1、RMUL: Eligibility to submit competition feedback.

2、RMUC:

a.Teams in both RMUC & RMUL: Eligibility for the Referee System Exam (Usage).

b.RMUC-only teams: Eligibility for Referee System Exam (Usage) + one set each of Hero, Infantry, and Sentry Referee System for borrowing.

*(Note: All times are in China Standard Time [CST]. )*
