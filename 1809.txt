RoboMaster 赛事交流活动支持方案

2025-01-06

为满足RM参赛队伍自发组织和参与交流赛、战队展示等活动需求，结合过往裁判系统短期借用背景情况，现推出全新交流活动支持方案，请各参赛队伍在举办活动前自行获取和评估申请。

*一、支持方案申请要求*

+------------+-------------------------------------------------------------------------------------+
|    维度    |                                      支持要求                                       |
+------------+-------------------------------------------------------------------------------------+
| 活动对象   | -活动发起方和所有参与方必须为                                                       |
|            | 已通过当前赛季机甲大师高校系列赛（含超级对抗赛、高校联盟赛）报名审核的队伍。        |
|            | -注意：若活动包含不符合上述条件参与方，支持方案中相关物资数量计算将不包含此类参与方 |
| 活动方案   | -活动规则、赛制等需适配组委会提供的技术方案（后续发布）及物资支持方案。             |
|            |  -申请时需提交： 活动策划文件（含规则、赛制等），用于审核确认。                     |
| 活动时间   | -支持的活动举办时间范围：  *                                                        |
|            | 物资支持：每年 9 月至次年 2                                                         |
|            | 月 * 技术支持：全年不限 -注：                                                       |
|            | 物资支持申请必须在活动举办日期前至少                                                |
|            | 2-4 周提交，以预留审核时间。                                                        |
| 活动影响力 | -组委会将综合评估以下因素，确定最终支持等级：                                       |
|            |  1）辐射范围：                                                                      |
|            | 至少需面向并覆盖战队所在院校的非战队成员。                                          |
|            |  2）组织单位级别：                                                                  |
|            | 活动主办单位至少为院级组织。  3）资源投入：                                         |
|            | 活动在资金、场地等方面的资源投入情况。                                              |
+------------+-------------------------------------------------------------------------------------+

*二、支持方案*

*1、物资支持*

1）赛事物资优惠折扣

* 通过审核的活动，其主办单位及参与活动的 RM 战队可获得额外赛事配件物资的教育折扣购买额度。
* 具体额度将根据活动方案和实际需求协商确定。

2）裁判系统短期借用

组委会将基于活动方案和预估影响力，提供不同等级的借用方案：

* A 等级： 为每支参与活动的 RM 战队提供3-5 套裁判系统，每个活动最多支持8支 RM 战队。
* B 等级： 为每个活动借用3-5 套裁判系统。

注： 最终借用数量会考虑参与队伍是否已有甲级队伍自留裁判系统等情况。

*2、技术方案支持*

为便于各参赛队伍开展赛事交流活动，组委会提供 RoboMaster 交流赛技术方案指南作为参考，请根据实际活动需求自行查阅： https://bbs.robomaster.com/article/1316686 ( https://bbs.robomaster.com/article/1316686 )

*该方案指南不提供额外技术支持，如对赛事产品的使用存在疑问，请按常规流程提交技术支持单，我们将及时协助解决。审核通过后，组委会将建立专属交流群，可用于活动举办讨论。
