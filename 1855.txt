RoboMaster 2025机甲大师超级对抗赛全国总决赛赛季总结须知

2025-08-08

参与对象：见 RoboMaster 2025机甲大师超级对抗赛区域赛获奖名单 ( https://www.robomaster.com/zh-CN/resource/pages/announcement/1847 ) ，"晋级复活赛”或“晋级全国赛"的参赛队伍均须完成

参与方式：以参赛队伍为单位，在 RoboMaster 论坛 ( https://bbs.robomaster.com/ ) 中完成撰写材料，通过队长账号登录 报名系统 ( https://registration.robomaster.com/registration-center ) 提交材料

提交时间：2025年8月15日18:00—8月18日18:00

提交机会：1次

通过条件：获得“C”及以上的等级

考查内容：总结文档、综合评估。

①根据参赛手册评审要求，在 R ( https://bbs.robomaster.com/ ) oboMaster 论坛 ( https://bbs.robomaster.com/ ) 战队功能中创建内容模板，选择对应的模板进行撰写，多配图表、流程图，数据充分，重点突出，逻辑清晰

《RoboMaster 2025机甲大师超级对抗赛全国总决赛赛季总结模板》（ 点击查看 ( https://bbs.robomaster.com/wiki/17105169 ) ）

②请点击下方链接进入并填写问卷，报名系统中的参赛队的正式队员均须填写，其中队长仅须填写队长版本问卷，无须再次填写正式队员版本问卷，每队链接相互独立。

RMUC 2025全国总决赛综合评估问卷链接： https://doc.weixin.qq.com/sheet/e3_AT4AdAZiAD8CNE11XPXhRSke1wg1u?scode=AC0A8gfyABENwaLuLJAT4AdAZiAD8&tab=BB08J2

问卷填写截止时间：8月20日18:00

通过权限：

1、获得全国赛获奖证书、参赛证明及奖金发放资格

2、由于赛季总结的内容与战队管理小组（含队长、副队长、项目管理）的工作内容高度相关，得分将作为“年度优秀队长（团）”及“年度优秀项目管理”评选的重要依据。获得奖项可获奖金5000元
