关于电池购买和安全使用规范说明

2025-02-21

一、电池购买安全要求

近期观察到参赛队在备赛使用电池的过程中存在安全隐患，根据此前发布的电池安全规范公告（ https://www.robomaster.com/zh-CN/resource/pages/announcement/1798 ），为保障人员安全及规范电池使用流程，使用电池的环境中必须配备消防设施。在研发备赛的任何时段，希望各参赛队员充分注意电池安全问题，防范于未“燃”。现更新以下电池购买要求：

1、所有电池采购申请单位/个人须确保实验室已配备以下安全设施

① 灭火器

② 防爆型电池存储箱

2、发送含有电池购买的物资出售清单至robomaster@ dji.com ( http://dji.com/ ) 审核时需将实验室的安全设施拍摄照片或视频作为邮件附件，照片或视频须含有证明拍摄地点材料，如门牌或战队标识等

二、RoboMaster 新电池安全说明

1、收到参赛队反馈的电池异常问题，存在电池开机瞬间进入短路保护状态的现象，组委会检测后判断原因是使用不规范导致触发了电池的保护机制，该异常问题的解决办法参见电池启动相关建议（ 点击下载 ( https://terra-1-g.djicdn.com/b2a076471c6c4b72b574a977334d3e05/%E7%94%B5%E6%B1%A0%E5%90%AF%E5%8A%A8%E7%9B%B8%E5%85%B3%E5%BB%BA%E8%AE%AE.pdf ) ）

DJI Matrice 4D 系列电池说明书（中文版）： 点击下载 ( https://terra-1-g.djicdn.com/b2a076471c6c4b72b574a977334d3e05/DJI_Matrice_4D_Series_Battery_User_Manual_v1.0_zh-cn.pdf )

DJI Matrice 4D 系列电池说明书（英文版）： 点击下载 ( https://terra-1-g.djicdn.com/b2a076471c6c4b72b574a977334d3e05/DJI_Matrice_4D_Series_Battery_User_Manual_v1.0_en.pdf )

PS：为确保电池使用安全，使用RoboMaster 新电池前自行确认是否存在上述场景，如存在请参考上方电池启动相关建议

2、异常问题反馈渠道

如因未作电池启动保护导致电池异常，请于2025年2月24日16:00前通过以下渠道进行反馈

a、按格式发送邮件至robomaster.support@ dji.com ( http://dji.com/ ) 邮件标题：【RoboMaster 新电池】+学校名称

b、邮件内容： ①联系信息（联系人、联系电话、联系地址）；②情况详细描述，包括使用环境（如串并联、负载情况等）、操作步骤、异常现象

3、常规技术咨询渠道
