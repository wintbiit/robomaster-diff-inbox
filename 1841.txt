Notice on RoboMaster 2025 University Championship and University League Referee System Exam (Usage)

2025-04-29

Participants:

1、RMUC: Teams that have passed the Mid-term Progress Assessment.

2、RMUL: Teams that have passed the RMUL 2025 Final Robot Assessment .

Passing Conditions:

A score of 95 or above is considered a pass. The questionnaire must include the respondent's name, and only submissions from regular members are valid. It is strongly recommended that the Captain and Pit Crew participate.

+--------------------+--------------------------------+--------------------------------+

|                    |                                | and sessions. For example,     |
|                    |                                | passing the 3V3 Match does     |
|                    |                                | not translate to passing       |

|                    |                                | participating member is a      |
|                    |                                | regular member in multiple     |
|                    |                                | events, their questionnaire    |
|                    |                                | submissions can be counted     |
|                    |                                | separately for the respective  |
|                    |                                | events.                        |
| 3V3 Match          | At least 4 passing submissions |
|                    | required.                      |
| Infantry Match     | At least 2 passing submissions |
|                    | required.                      |
| Engineer Challenge | At least 2 passing submissions |
|                    | required.                      |
+--------------------+--------------------------------+--------------------------------+

Participation Method:

1、Team-based participation.

2、To simplify the evaluation process, given the potential for teams to register for multiple events with varying time slots based on location/type, participation will occur via the following links and schedules:

①RMUL Chinese Mainland : February 24, 2025, 18:00 - February 26, 2025, 18:00; Exam link: https://djistore.wjx.cn/vm/tBhRFmN.aspx

②RMUL North America: April 29, 2025, 18:00 - May 2, 2025, 18:00：Exam link: https://djistore.wjx.cn/vm/rkBCZW2.aspx

③RMUC Chinese Mainland: February 24, 2025, 18:00 - February 26, 2025, 18:00; Exam link: https://djistore.wjx.cn/vm/eJnPi6L.aspx

④RMUC Hong Kong, Macau, Taiwan, and Overseas Teams: April 29, 2025, 18:00 - May 2, 2025, 18:00; Exam link: https://djistore.wjx.cn/vm/wF2PPFb.aspx

Exam Format:

Teams must submit the exam within 60 minutes.

Exam Attempts:

Participants can attempt the exam multiple times during the valid period. Once the passing criteria are met, the team passes the session.

Permissions Upon Passing:

1、RMUL: Gain permission for on-site competition.

2、RMUC: Gain permission for Final Robot Assessment.
