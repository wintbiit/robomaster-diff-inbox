RoboMaster 2025机甲大师超级对抗赛及高校联盟赛裁判系统测评（使用测评）须知

2025-02-24

参与对象：

1、RMUC：所有已通过裁判系统测评（基础测评）环节的队伍

2、RMUL：所有已通过RMUL 2025完整形态考核环节的队伍

通过条件：

一份答卷分数达到98分（含）以上视为通过。答卷须填写姓名，仅正式队员的答卷有效，强烈建议队长及场地队员必须参与

+------------+--------------------------+---------------------------------------------------------------------------+
|    赛项    | 通过条件（以队伍为单位） |                                备注说明：                                 |
+------------+--------------------------+---------------------------------------------------------------------------+
| RMUC       | 至少10份答卷通过         | 1、赛事与 赛项通过条件相互独立， 例如通过                                 |
|            |                          | 3V3 对抗赛不视为自动通过步兵对抗赛                                        |
|            |                          | 2、同一参赛队员在多赛项中均为正式队员，其答卷可分别纳入对应赛项的通过统计 |
| 3V3对抗赛  | 至少4份答卷通过          |
| 步兵对抗赛 | 至少2份答卷通过          |
| 工程挑战赛 | 至少2份答卷通过          |
+------------+--------------------------+---------------------------------------------------------------------------+

参与方式：

1、以队伍为单位

2、由于存在参赛队伍同时报名多个赛事、不同站点/类型队伍参与时间不一致的情况，为简化测评流程，通过以下问卷星链接和测评时间进行：

RMUL内地站点测评时间：2025年2月24日18:00-2025年2月26日18:00；测评链接： https://djistore.wjx.cn/vm/tBhRFmN.aspx

RMUL北美站点测评时间：2025年4月29日18:00-2025年4月30日18:00；测评链接：后续更新

RMUC内地队伍测评时间：2025年2月24日18:00-2025年2月26日18:00：测评链接： https://djistore.wjx.cn/vm/eJnPi6L.aspx

RMUC港澳台及海外队伍测评时间：2025年4月28日18:00-2025年4月30日18:00；测评链接：后续更新

测评内容： 《 RoboMaster 裁判系统用户手册 ( https://rm-static.djicdn.com/tem/13194/RoboMaster%20%E8%A3%81%E5%88%A4%E7%B3%BB%E7%BB%9F%E7%94%A8%E6%88%B7%E6%89%8B%E5%86%8CV1.3.pdf ) 》、 裁判系统各模块的说明书 ( https://www.robomaster.com/zh-CN/products/components/referee ) （同2020赛季）、 裁判系统FAQ ( https://www.robomaster.com/zh-CN/products/components/referee?djifrom=nav ) 等裁判系统相关文件

测评形式：50道选择题（随机生成），满分100分，每道题2分。参赛队伍需在120分钟内提交答卷。

测评次数：环节有效时间内可重复做题，一旦达到及格要求则通过该环节

通过权限：

1、RMUL：获得线下比赛权限

2、RMUC：获得完整形态考核的提交权限
