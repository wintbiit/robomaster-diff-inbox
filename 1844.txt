RoboMaster AWARD 2025 评选公告

2025-05-09

--------------------------------------------------------------------------------------------------------------------------------------------------
RoboMaster AWARD（以下简称“RM AWARD”）是自2024赛季起设立的个人荣誉奖项，每赛季评选、表彰一次。为宣扬卓越青年工程师文化精神，发挥榜样力量，倡导 RoboMaster 参赛队员践行赛事文化价值观、积极发挥个人影响力，因此对所在队伍参赛有显著贡献的优秀个人予以鼓励。
--------------------------------------------------------------------------------------------------------------------------------------------------

RM AWARD 2025将按照技术和管理两个方向分别评选，评选流程由队伍推荐、提交申请材料、材料筛选、面试评选等环节组成。

*一、评选标准*

+--------------------+-----------------------------------------------------------------------------------------------------------------------------------------+
|        方向        |                                                                标准要求                                                                 |
+--------------------+-----------------------------------------------------------------------------------------------------------------------------------------+
| *RM AWARD（技术）* | 1、在日常研发工作中，能践行格物致知的赛事文化和精神： -有学习意愿和能力，对于新的知识领域能探究原理并应用到实际的研发任务中；           |
|                    | -追求挑战、迎难而上，在技术先进性/瓶颈问题上有显著贡献，且个人精神影响团队其它人更好地追求技术突破；                                    |
|                    | 2、申请材料的核心内容，需为比赛中申请人首次实现或者较其它已有方案有明显的突破或改进，且技术方案在备赛过程中或比赛过程中有实际应用落地。 |
| *RM AWARD（管理）* | 1、有管理意识，主动沉淀管理制度进行队内人员、进度、成本管理，带领队伍达成目标；                                                         |
|                    | 2、思考力强，能抓主要矛盾、能分析问题根因；能识别队内风险、进行重大决策；                                                               |
|                    | 3、上进心强，有高要求，积极攻坚克难，勇于打破限制；做到以身作则，带头践行赛事文化和精神；                                               |
|                    | 4、申请材料的核心内容，需是申请人任职以来主要贡献和优化的内容。                                                                         |
+--------------------+-----------------------------------------------------------------------------------------------------------------------------------------+

*二、申请条件*

+--------------------------------------------------------------------------+--------------------------------------------------------------------------+----------------------------------------------------+
|                                 申请条件                                 |                             RM AWARD（技术）                             |                  RM AWARD（管理）                  |
+--------------------------------------------------------------------------+--------------------------------------------------------------------------+----------------------------------------------------+
| 参赛身份                                                                 | * RMUC 2025                                                              | RMUC 2025                                          |
|                                                                          | 区域赛队伍正式参赛队员 * RMUA 2025                                       | 区域赛队伍队长、副队长、项目管理、运营经理         |
|                                                                          | 线上赛决赛队伍队员可参与算法方向评选                                     |                                                    |
| 参赛经历                                                                 | 所在队伍获得RMUC 2025                                                    | * 所在队伍获得RMUC 2025                            |
|                                                                          | 区域赛正式比赛参赛资格                                                   | 区域赛正式比赛参赛资格 *                           |
|                                                                          |                                                                          | 参与RMUC 至少2年                                   |
| 所在队伍有良好的竞技精神，不存在严重违反比赛规则和文明比赛精神的违规行为 | 所在队伍有良好的竞技精神，不存在严重违反比赛规则和文明比赛精神的违规行为 |
| 成果贡献度                                                               | 申请材料中所描述的技术内容，申请人需为最主要的贡献者                     | 申请材料中所描述的技术内容，申请人需为主要的贡献者 |
| 注：同一申请人可同时申请参与技术和管理两个方向评选                       |
+--------------------------------------------------------------------------+--------------------------------------------------------------------------+----------------------------------------------------+

*三、评选流程*

1、队伍推荐确认申请人：RMUC 2025、RMUA 2025 参赛队伍参照评选标准和申请条件推荐各队伍 RM AWARD 申请人（不限人数），以参赛队伍为单位，通过队长账号登录 报名系统 ( https://registration.robomaster.com/registration-center ) ，在所属赛事“RM AWARD 申请人推荐”环节提交所有申请人名单，共计两次提交机会

2、队伍提交申请材料：被推荐人下载申请材料模板，按照模板内容准备成果说明材料和推荐信，以参赛队伍为单位，通过队长账号登录 报名系统 ( https://registration.robomaster.com/registration-center ) ，在所属赛事“RM AWARD 申请材料提交”环节提交队伍所有申请人材料，共计两次提交机会

* *RM AWARD 2025（技术）申请材料模板下载* ( https://terra-1-g.djicdn.com/b2a076471c6c4b72b574a977334d3e05/RM2025/RM%20AWARD%202025%EF%BC%88%E6%8A%80%E6%9C%AF%EF%BC%89%E7%94%B3%E8%AF%B7%E6%9D%90%E6%96%99%E6%A8%A1%E7%89%88.docx )
* *RM AWARD 2025（管理）申请材料模版下载* ( https://terra-1-g.djicdn.com/b2a076471c6c4b72b574a977334d3e05/RM2025/RM%20AWARD%202025%EF%BC%88%E7%AE%A1%E7%90%86%EF%BC%89%E7%94%B3%E8%AF%B7%E6%9D%90%E6%96%99%E6%A8%A1%E7%89%88.docx )

填写注意事项：
1）申请材料的撰写请保留原模板字体、字号及格式，导出pdf格式文件，文件命名规范： *RM AWARD 2025 申请材料-校名-姓名-参评方向（机械/嵌入式/算法/硬件/管理）
* 2）申请材料中可附上相应内容的佐证材料，如图片、视频链接等，视频资源清晰度需高于720P并控制在15分钟内

3、材料筛选确认提名奖名单：评审委员会将根据申请人材料进行筛选，通过筛选的候选人将获得 RM AWARD 提名奖

4、面试评选最终获奖人名单：候选人参与 RM AWARD 面试评选，通过面试评选的人员将获得最终 RM AWARD 奖项

*四、奖项设置*

1、奖金：

* RM AWARD 获奖人可获得奖金人民币 8,000元/人（税前）

2、荣誉品：

* RM AWARD 候选人可获得RoboMaster AWARD 2025 纪念牌
* RM AWARD 获奖人可获得RoboMaster AWARD 2025 纪念奖杯

3、招聘权益：

* RM AWARD 2025 候选人可获得 DJI 大疆校园招聘【初面直通卡】
* RM AWARD 2025 获奖人可获得 DJI 大疆 2026 秋季校园招聘【二面直通卡】

注：
1）二面直通卡仅限 2026 届毕业生使用，若非应届则转为初面直通卡，初面直通卡可顺延至应届投递时使用
2）RM AWARD（技术）候选人需在校招投递与参评方向一致的岗位才可享受招聘权益
3）2026届应届候选人如投递岗位与评选方向一致时，奖项评选面试环节即为校招岗位初面

*五、2025赛季评选时间节点*

1、队伍推荐：2025年6月3日18:00-6月5日18:00（北京时间）

2、提交申请材料：2025年6月10日18:00-6月15日18:00（北京时间）

3、提名奖（候选人）公示：2025年7月中旬

4、面试评选：2025年8月中旬

6、获奖公示：2025年8月下旬

本奖项评选方案最终解释权归RoboMaster 组委会所有，如有任何疑问，请联系RoboMaster 高校赛务（微信：rmsaiwu）。
