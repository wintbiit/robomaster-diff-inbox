RoboMaster 2025机甲大师超级对抗赛完整形态考核须知

2025-03-13

参与对象：

1、所有已通过中期进度考核的参赛队伍

2、港澳台及海外参赛队伍无须参与本次考核，后续将另行安排

参与方式：以参赛队伍为单位，在 RoboMaster 论坛 ( https://bbs.robomaster.com/ ) 中完成撰写材料，通过队长账号登录 报名系统 ( https://registration.robomaster.com/registration-center ) 提交材料

完整形态展示提交时间：2025年3月24日18:00—2025年3月26日18:00（北京时间）

项目文档&技术方案提交时间：2025年3月24日18:00—2025年3月31日12:00（北京时间）

提交机会：1次

通过条件：根据完整形态展示考核的分数进行排序。内地队伍中，排名前96的队伍可通过；港澳台及海外队伍中，同标准下的若干队伍可通过

考查内容：按《 RoboMaster 2025机甲大师超级对抗赛参赛手册 ( https://www.robomaster.com/zh-CN/resource/pages/announcement/1653 ) 》中的完整形态考核要求，参考以下内容进行准备。

1、完整形态展示：按 《RoboMaster 2025机甲大师高校系列赛技术评审进度考核细则》 ( https://www.robomaster.com/zh-CN/resource/pages/announcement/1772 ) 中的顺序，录制视频素材，展示每个兵种的实际完成情况请尽可能展示更多完成进度；为防止视频素材重复使用，导致展示进度与实际不符的问题，请各参赛队根据实际情况在拍摄过程中选择以下其中一种方式完成拍摄/提交证明材料。未按此要求拍摄的素材片段/提交证明材料，对应内容的得分至高仅可获得满分的50%。

a.（ 点击此处 ( https://terra-1-g.djicdn.com/b2a076471c6c4b72b574a977334d3e05/2025%E5%AE%8C%E6%95%B4%E5%BD%A2%E6%80%81%E8%80%83%E6%A0%B8%E8%B4%B4%E7%BA%B8.pdf ) ）下载技术评审装甲图，打印并张贴到机器人装甲板或装甲板预留安装位置上。无须安装装甲板的机器人，如空中机器人等，请采用b方式拍摄视频

b.（ 点击此处 ( https://terra-1-g.djicdn.com/b2a076471c6c4b72b574a977334d3e05/2025%E5%AE%8C%E6%95%B4%E5%BD%A2%E6%80%81%E8%80%83%E6%A0%B8%E8%83%8C%E6%99%AF.pdf ) ）下载技术评审背景板，在视频拍摄过程中，使用A3纸打印、笔记本全屏或其他实物方式全程清晰展示技术评审背景板，禁止后期合成

视频素材录制完成后，进入论坛-我的战队-创建内容-选择RMUC 2025完整形态考核模板（ 点击查看 ( https://bbs.robomaster.com/wiki/8497362 ) ）创建文档，在每页中按标题插入对应的视频素材片段

数据记录表：参考《RoboMaster 2025机甲大师超级对抗赛技术评审数据记录表模板》（模板下载： 点击此处 ( https://terra-1-g.djicdn.com/b2a076471c6c4b72b574a977334d3e05/RMUC%202025%E6%8A%80%E6%9C%AF%E8%AF%84%E5%AE%A1%E6%95%B0%E6%8D%AE%E8%AE%B0%E5%BD%95%E8%A1%A8(%E6%A8%A1%E6%9D%BF).xlsx ) ），提交Excel文档

2、技术方案和项目文档（模板后续更新）：根据评审要求，在 R ( https://bbs.robomaster.com/ ) oboMaster 论坛 ( https://bbs.robomaster.com/ ) 战队功能中创建内容模板，选择对应的模板进行撰写，多配图表、流程图，数据充分，重点突出，逻辑清晰

提交要求：

1、视频：视频大小在500M内，视频文件编码格式为H.264/AVC或MPEG-4，清晰度 720P；配有字幕或提示板，解释视频中每一个过程；只展示有效内容，视频节奏紧凑，单个兵种功能展示时间不超过10min

2、文档命名：RMUC2025+校名+队名+完整形态考核

通过权限：

1、获得全套裁判系统借用权限 和参赛反馈的提交权限

2、该环节的“项目文档”和“技术方案”得分将影响该参赛队伍区域赛期间每局比赛的初始金币数量。
